# 英语大师 English360

面向**中文母语、零基础成人**的长期英语能力学习系统（PWA）。

目标不是“完成 360 天课程”，而是通过系统化、自适应、以真实能力为导向的训练，
最终达到 **Native-like Functional Proficiency**（美国英语功能流利）。360 天只是第一个大里程碑；
系统根据**真实能力**而不是日历决定学习路径，一年未达标则继续学习。

> 注意：本项目是独立的新项目，与旧 `english360` 项目无关，可独立部署、独立维护。

---

## 快速开始

项目是纯静态站点（无构建步骤），直接用任意静态服务器打开即可：

```bash
# 任意一种即可
python3 -m http.server 8000
npx serve .
```

> ⚠️ 不能直接双击打开 `index.html`（`fetch` 加载数据在 `file://` 下会被拦截）。
> 开发时请用 `http://localhost:8000` 访问，PWA / Service Worker 需要 HTTP(S) 环境。

## 部署 (GitHub Pages)

推送到 `main` 分支即自动触发 [.github/workflows/pages.yml](.github/workflows/pages.yml) 部署到 GitHub Pages。
安装到 iPhone 的步骤：

1. 用 iOS Safari 打开站点；
2. 点击「分享」→「添加到主屏幕」；
3. 之后以独立窗口（standalone）运行，可离线学习。

### 核心能力系统

- **SRS 间隔重复引擎**（`js/srs.js`）：SM-2 变体，每词独立 ease/interval/reps/lapses，学习步 + 复习态，
  答错自动重排，最长间隔 180 天封顶。
- **Student Model 学生模型**（`js/student.js`）：10 个技能维度（词汇/语法/听力/口语/阅读/写作/发音/流利度/自然度/记忆保持），
  加权移动平均记录真实能力，弱项自动进入今日计划。
- **Error Bank 错误银行**（`js/errors.js`）：记录错误的类别、频次、复发、纠正状态；未纠正错误生成「错题强化」训练。
- **每日计划器**（`js/planner.js`）：按时间预算（30-240 分钟）+ 强度 × 分配 SRS 复习/路径任务/弱项/输入/输出。
- **自适应设置**：模式（自动/手动）、强度（轻松/标准/强化/极限）、严格度（宽松/标准/严格/极严），全部由用户控制，系统不偷偷改动。
- **XP / 成就**（`js/achievements.js`）：只奖励真实学习行为，成就由真实里程碑触发。

## C2 可达性 · 诚实评估（2026-09 数据优化后）

目标（零基础 → C2 / 美国英语功能流利）**方向可行，但要如实看待三件事**：

**① 本系统是完整的「脚手架」，但不是全部。** 达到 C2 需要约 1,500–2,500 小时的
刻意练习 + 大量真实输入输出。本系统提供了其中可持续自习的部分：拼读体系、
按真实语料频率分级的 20,000 词、SRS 记忆引擎、87+550 语法精讲、分级听读材料、
口语跟读/情景对话、写作批改、自适应测试与毕业考试。

**② 数据质量优先于数据数量（本次优化的核心）。** 原词库按「Collins星级→BNC→频率」
字典序截取 55,000 词，由于 ECDICT 仅约 5.7万/40万 词带真实语料频率信号，导致大量
无频词/公司名/医学词混入初级（如 L1 出现 based/folliculitis），且 L5 中 40% 缺音标、
例句全是同一模板句；增强文件含模板编造的伪同义词/伪搭配。**已全部重建**：

| 项 | 优化前 | 优化后 |
|---|---|---|
| 词库深度 | 55,000 词（含 3 万+无频噪声词） | **20,000 词全部有 BNC/COCA/Collins 真实语料证据** |
| L1 前50词 | 与课程声称不符（based/folliculitis 混入） | the/be/of/and/a/in/to/have... 与第8课完全一致 |
| 音标缺失 | L5 达 19,833/47,000 (42%) | 全库 7.2%（均为 etc/others 类功能词） |
| 例句 | 98% 为同一模板句 | 功能词手写真实例句 + 实词按词性多模板，中英一一对应 |
| 增强数据 | 伪同义词/伪搭配（"him 用法"） | 真实词根(wordroot.txt) + 真实词形变化 + WordNet 英英释义 + 真实语料频率 |
| 文件体积 | 19.5MB | 6.0MB（首载提速 3 倍） |

**③ 到 C2 还缺什么（建议路线）：** 系统内的 120 篇短文/50 段对话适合 L1-L4；
C2 阶段（L5）必须补充**海量真实输入**——原版小说/美剧/播客/YouTube（
系统已内置 B 站/YouTube 分级视频索引与免费资源库作桥梁），以及**真人对话**
（AI 问答可练语言形式，不能替代与人的真实交流）。理性预期：每天 2-4 小时
认真使用本系统，约 1.5-2.5 年可达到 C1（能应付工作/学术/生活绝大部分场景），
之后靠真实语料沉浸冲 C2。任何承诺「360 天从零到 C2」的产品都是营销话术。

## 数据与隐私

- 所有学习数据**仅存本地**（localStorage）：进度 + 学生模型 + 错误银行 + 成就 + SRS 卡片；
  可在设置中「导出进度」备份，到新设备「导入进度」继续学习。
- **不会**把 GitHub Pages 当作数据库；未来通过 Sync Adapter 接入云同步（见架构文档）。

## AI 配置（可选）

设置 → AI 问答接口，支持 OpenAI 兼容 API：Agnes AI / OpenAI / DeepSeek / 通义千问 / 豆包 / SiliconFlow / Azure / 自定义。

- API Key **只保存在浏览器本地**（localStorage），不会写入代码或 GitHub Pages 静态文件；
- 未配置 AI 时，核心学习系统（课程/词汇/语法/SRS/测试/进度/自适应）**完全可用**，AI 仅作为增强层。

## 已知限制（诚实声明）

- 口语发音评分依赖浏览器 Web Speech API：iOS Safari 不支持识别，自动降级为自评（跟读对照）。
- 语音合成为系统 TTS（Web Speech API），音色/口音随设备而异。
- `vocabulary.json` ≈ 6MB，首次加载需数秒；Service Worker 缓存后离线秒开。
- 本地存储使用 localStorage（5MB 上限）：SRS 卡片约 150 字节/词，一万词约 1.5MB，可承受；
  若未来用户词量极大，迁移到 IndexedDB 即可（数据 schema 已带版本号）。
